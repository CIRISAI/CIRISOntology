# DYNAMIC GRAY ALGEBRA — preregistered structural screen

Frozen 2026-08-22 before `dynamic_gray_algebra.py` exists or any output is read.

The static Tavis–Cummings screen closed the time-independent Hamiltonian SOTA route: ordinary Krylov captured the photon-reachable sector in 8/16/32/96 states across N=256..1024, substantially below defect-based emitter clustering. Current MPS–HEOM work identifies **dynamic disorder** as the harder polariton regime because it continually activates non-collective dark/gray degrees of freedom.

This screen asks the exact structural question that must be answered before proposing a bath-aware soft-symmetry compiler:

> Does low-rank correlated dynamic disorder imply a low-dimensional invariant bright+gray sector?

The answer is not assumed to be yes.

## Model object

Uniform-coupling single-excitation ensemble. Let `|B> = N^-1/2 (1,...,1)` in emitter space. Dynamic diagonal disorder is generated by `r` spatial profiles `a_alpha in R^N` with arbitrary scalar time processes `xi_alpha(t)`:

`D(t) = sum_alpha xi_alpha(t) diag(a_alpha)`.

Define `A` as the `N x r` matrix whose rows are emitter profile vectors

`A_i = (a_1(i),...,a_r(i))`.

Two emitters are **bath-equivalent** iff their complete row profiles are identical:

`i ~ j iff A_i = A_j`.

Let `G(A)` be the number of equivalence classes.

## Exact algebraic claim under test

Because all disorder operators are diagonal and commute, the unital algebra they generate consists of diagonal functions of the row profile. On a finite set, polynomial interpolation separates distinct row profiles. Therefore the smallest emitter subspace containing `|B>` and invariant under every `diag(a_alpha)` should have dimension exactly

`dim R_emit = G(A)`

when all bright amplitudes are nonzero. Including the cavity gives `1 + G(A)`.

This is a finite-dimensional algebra statement, not a stochastic approximation and not a claim about HEOM hierarchy size.

## Direct gray-rank diagnostic

The first-order bright→dark drives are

`q_alpha = Q_dark diag(a_alpha)|B>`.

Their span has dimension

`r_direct = rank([q_1 ... q_r]) <= r`.

Crucially, `r_direct` need not equal `G(A)-1`: repeated action of the same diagonal profile can generate new vectors. K2's instantaneous dark/bright coupling is the one-direction version of `q_alpha`; the algebra closure is its dynamic continuation.

## Frozen constructions

For `N in {16,32,64,128}`:

1. **COMMON**: one profile, `a_1(i)=1` for all i.
   - predicted `r_direct=0`, `G=1`, cavity+emitter invariant dimension 2.
2. **GROUP4**: one-hot membership in four equal groups (`r=4`; rows are four basis labels).
   - predicted `r_direct=3`, `G=4`, invariant dimension 5.
3. **GROUP8**: eight equal groups.
   - predicted `r_direct=7`, `G=8`, invariant dimension 9.
4. **RANK1-GENERIC**: a single profile with all entries distinct, fixed exact integers `a_1(i)=i`.
   - covariance/spatial profile rank = 1;
   - predicted `r_direct=1` but `G=N`, invariant dimension `N+1`.
   - this is the decisive counterexample to `low bath rank => small dynamic sector` if verified.
5. **RANK2-GENERIC**: profiles `(i, i^2 mod p)` with prime `p > N`, so every row tuple is distinct.
   - predicted `r_direct<=2`, `G=N`, invariant dimension `N+1`.
6. **LOCAL**: `r=N`, profiles are the standard basis, representing independently addressable local diagonal fluctuations.
   - predicted `r_direct=N-1`, `G=N`, invariant dimension `N+1`.

All profile constructions are deterministic; no random seed enters the exact tier.

## Independent numerical closure check

Do not certify the algebra claim from `G(A)` alone. Independently construct the Krylov-like closure from the bright vector under all diagonal generators:

- start basis with `B`;
- repeatedly apply each `diag(a_alpha)` to every newly accepted basis vector;
- orthogonalize and add vectors above relative tolerance `1e-10`;
- stop at fixed point or N.

Report the numerical closure dimension and require equality with `G(A)` on all constructions where conditioning remains resolvable. For RANK1-GENERIC use a normalized profile mapped to `[-1,1]`; if monomial conditioning prevents resolving all N directions, report `NUMERIC-CONDITIONING` rather than treating it as a theorem failure. The exact class-count statement remains separately checkable.

## Stakes

D1: COMMON / GROUP4 / GROUP8 reproduce the predicted direct ranks and exact class-count dimensions.

D2: RANK1-GENERIC has `r_direct=1` but `G=N` for every N. If so, the naive low-covariance-rank compiler hypothesis is **killed exactly**.

D3: LOCAL has direct gray rank `N-1` and `G=N`, demonstrating why independent dynamic disorder naturally activates an extensive gray sector.

D4: Numerical closure agrees with class-count dimension when numerically well conditioned. Disagreement is instrument failure unless explicitly attributable to the frozen conditioning rule.

## Simulation consequence

If D2/D3 pass, the next candidate is **not** “compress baths by covariance rank.” A viable open-system compiler must instead exploit approximate equivalence / low complexity of the full bath-coupling **row profiles**, tensor entanglement, or finite-time approximate algebra closure.

That moves the question close to chemistry: what spatial correlation structure of molecular vibrations produces few bath-equivalence/near-equivalence classes, and does that structure occur in realistic polaritonic systems? Independent local baths are the adversarial case and should not be promised a symmetry speedup.

## Prior-art fence

This screen claims no priority for commutative diagonal algebras, polynomial interpolation, correlated-bath reductions, TTN-HEOM, HOPS, pseudomodes, or MPS–HEOM. Its contribution is diagnostic: bringing the exact dark/bright symmetry-breaking object from K2 into a falsifiable criterion for when dynamic disorder can or cannot leave a small collective sector.
