### Derivation for MODE SET A: Jakobson's six functions of language

**R1 - Content Sites:**  
There are 6 modes, so 6 content sites.  
- Referential: about the context (conveying states of affairs)  
- Emotive: about the addresser (expressing attitude)  
- Conative: about the addressee (vocative/imperative engagement)  
- Phatic: about contact (channel maintenance)  
- Metalingual: about the code (language itself)  
- Poetic: about the message (form for its own sake)  

**R2 - Gap Sites (argued from each mode's satisfaction conditions):**  
- Referential: Satisfaction is when conveyed information matches facts. Gap: The performance (uttering a statement) can occur without the facts matching (e.g., lying or error). So, there is 1 gap: factual accuracy.  
- Emotive: Satisfaction is when expression matches actual attitude. Gap: The performance (expressing) can occur without the attitude being genuine (e.g., insincerity). So, 1 gap: sincerity.  
- Conative: Satisfaction is by addressee's uptake or compliance. Gap: The performance (issuing a call) can occur without uptake (e.g., ignored command). So, 1 gap: addressee response.  
- Phatic: Satisfaction is when the channel holds. Gap: The performance (making contact) can occur without the channel actually being functional (e.g., dead phone line). So, 1 gap: channel functionality.  
- Metalingual: Satisfaction is when agreement on code is reached. Gap: The performance (discussing code) can occur without agreement (e.g., misunderstanding terms). So, 1 gap: code agreement.  
- Poetic: Satisfaction is by the message's form doing its work. Gap: The performance (crafting message) can occur without the form achieving its effect (e.g., failed artistry). So, 1 gap: aesthetic efficacy.  

Total gaps: 6 (one per mode).

**R3 - Carrier Sites:**  
3 sites: encoding, presentation, instance token.

**Sites Enumerated and Named (skipping R4, naming each site):**  
1. Referential content site (what is conveyed about context)  
2. Emotive content site (what is expressed about addresser's attitude)  
3. Conative content site (what is engaged about addressee)  
4. Phatic content site (what is maintained about contact)  
5. Metalingual content site (what is glossed about code)  
6. Poetic content site (what is crafted about message form)  
7. Referential gap site (factual accuracy)  
8. Emotive gap site (sincerity)  
9. Conative gap site (addressee response)  
10. Phatic gap site (channel functionality)  
11. Metalingual gap site (code agreement)  
12. Poetic gap site (aesthetic efficacy)  
13. Carrier site: encoding  
14. Carrier site: presentation  
15. Carrier site: instance token  

**Total:** |M| = 6, gaps = 6, carriers = 3 → 6 + 6 + 3 = 15

### Derivation for MODE SET B: Recognition triple

**R1 - Content Sites:**  
There are 3 modes, so 3 content sites.  
- State-recognition: about the world being thus  
- Transition-recognition: about a transition being available/required  
- Constitution: about making-so  

**R2 - Gap Sites (argued from each mode's satisfaction conditions):**  
- State-recognition: Satisfied iff the recognized state actually obtains. Gap: The performance (recognizing) can occur without the state obtaining (e.g., misperception). So, 1 gap: state actuality.  
- Transition-recognition: Satisfied iff the transition is genuinely available/required. Gap: The performance (recognizing transition) can occur without it being available/required (e.g., misjudging possibility). So, 1 gap: transition genuineness.  
- Constitution: Satisfied by its own successful performance (the status comes to obtain because performed and accepted). There is no gap argued from these conditions: satisfaction is defined by the performance itself (it makes-so). If it fails, it is not satisfied, but the gap is not independent—the performance and satisfaction are co-dependent. Thus, no gap site for constitution.  

Total gaps: 2 (only for state-recognition and transition-recognition).

**R3 - Carrier Sites:**  
3 sites: encoding, presentation, instance token.

**Sites Enumerated and Named:**  
1. State-recognition content site (what is recognized about state)  
2. Transition-recognition content site (what is recognized about transition)  
3. Constitution content site (what is made-so)  
4. State-recognition gap site (state actuality)  
5. Transition-recognition gap site (transition genuineness)  
6. Carrier site: encoding  
7. Carrier site: presentation  
8. Carrier site: instance token  

**Total:** |M| = 3, gaps = 2, carriers = 3 → 3 + 2 + 3 = 8

### Derivation for MODE SET C: Habermas's three validity claims

**R1 - Content Sites:**  
There are 3 modes, so 3 content sites.  
- Truth: about the objective world  
- Rightness: about the social world of norms  
- Truthfulness: about the subjective world  

**R2 - Gap Sites (argued from each mode's satisfaction conditions):**  
- Truth: Satisfied iff the asserted state of affairs obtains. Gap: The performance (asserting) can occur without the state obtaining (e.g., false claim). So, 1 gap: objective truth.  
- Rightness: Satisfied iff the act is legitimate under norms. Gap: The performance (acting) can occur without legitimacy (e.g., norm violation). So, 1 gap: normative legitimacy.  
- Truthfulness: Satisfied iff the expression matches the inner state. Gap: The performance (expressing) can occur without matching (e.g., deceit). So, 1 gap: subjective sincerity.  

Total gaps: 3 (one per mode).

**R3 - Carrier Sites:**  
3 sites: encoding, presentation, instance token.

**Sites Enumerated and Named:**  
1. Truth content site (what is claimed about objective world)  
2. Rightness content site (what is claimed about social norms)  
3. Truthfulness content site (what is claimed about subjective world)  
4. Truth gap site (objective truth)  
5. Rightness gap site (normative legitimacy)  
6. Truthfulness gap site (subjective sincerity)  
7. Carrier site: encoding  
8. Carrier site: presentation  
9. Carrier site: instance token  

**Total:** |M| = 3, gaps = 3, carriers = 3 → 3 + 3 + 3 = 9
