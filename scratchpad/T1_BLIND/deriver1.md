# deriver-1, verbatim (order: A=Jakobson, B=recognition, C=Habermas)

BLIND DERIVATION, pass 1. Tools not used; worked only from the brief. Totals: A=24, B=18, C=16 (deduplicated: 23, 16, 16).

TWO STANDING RULES, applied identically to all three sets:
(i) A gap site counts only if I can state a case where THAT THING ALONE fails while the mode is fully performed and every other site holds, and the failure is derivable from the satisfaction condition as the brief states it. A dimension along which some other site fails (degree, precision, timing) is a coordinate of that site, not a site.
(ii) R3 already owns encoding, presentation, token — so "wrong words / badly delivered / wrong copy" is never a gap, however tempting a mode makes it.

MODE SET A — Jakobson's six

(a) R2 GAP ARGUMENTS

REFERENTIAL (conveyed information matches the facts).
1. The match is with THE facts — those of the context the message is oriented to, orientation-to-context being what defines the mode. Performance fixes which context; that fixing fails independently of content. An exactly accurate description of Tuesday's meeting delivered as a report on the meeting actually in play is unsatisfied with nothing wrong in the description.
2. Information is conveyed at a strength. What "certainly p" conveys includes a claim about how well established p is, and that claim has its own truth value. True proposition asserted as certain when it was a guess: false at strength, true at content. Properly hedged proposition that turns out false: true at strength, false at content. They flip independently.
3. Conveying also carries what is relied on but not asserted. "Your replacement arrives Tuesday" fails to match the facts when no replacement was ordered, though no asserted sentence is false.
REJECTED: a scheme-of-carving site. Jakobson supplies a dedicated metalingual mode, so the code and its fit have their own mode; charging a carving gap here counts the code twice.

EMOTIVE (expression matches the ACTUAL attitude).
"Actual" opens two joints, not one. The display can diverge from what the speaker takes their attitude to be (feigning); what they take it to be can diverge from what it is (self-misreading). A wholly sincere speaker fails the second with the first intact, so they are separately failable.
REJECTED: intensity. Right attitude at the wrong strength IS the display failing to be faithful — a coordinate of joint 1.

CONATIVE (addressee's uptake or compliance).
1. Satisfaction is another party's act, so one gap exists by construction: they may simply not take it up, performance flawless.
2. Compliance presupposes the person addressed is the person meant — a correct order aimed at the wrong person leaves the right one never asked.
3. And separately that they are able: right person, willing, unable.
4. Compliance is compliance WITH A DEMAND, which requires the demand to have force for them. A demand from someone with no standing can be understood, correctly addressed, addressed to an able and even willing party, and still draw nothing, precisely because standing is absent.

PHATIC (the channel in fact holds).
1. The channel may be down — the gap the condition names directly.
2. Contact is two-sided in a way the channel is not: the line can be open while the other party is not attending, and attention can be present on a failing line.
REJECTED: persistence over time — a coordinate of holding.

METALINGUAL (agreement on the code is reached).
1. Agreement is another party's; they may fail to converge with the gloss impeccable.
2. Conducting a repair at all needs enough shared sub-code to conduct it in. That precondition can be absent while nothing is wrong with the proposed gloss, and its absence is not a failure to converge on this item.
FEATURE OF THE STATED CONDITION, flagged: satisfaction is AGREEMENT REACHED, not GLOSS CORRECT. So this mode alone in set A generates no correctness gap — two parties can agree on a gloss that misdescribes the code and the mode is satisfied as stated.

POETIC (the message's own palpable form doing its work).
1. Satisfaction is form-internal — this is the one mode whose content site and vehicle nearly coincide. The construction can be exactly as designed and still not do the work it was built for. Distinct from the presentation carrier: the failure is in the shape, not in the rendering of the shape.
2. The condition says the work is done by the message's OWN form. An effect achieved entirely by the shocking content a line carries, rather than by its shape, does not satisfy. Attribution is separately failable. (Most speculative gap in set A.)

Σ gaps = 3 + 2 + 4 + 2 + 2 + 2 = 15.

MODE SET B — the recognition triple

(a) R2 GAP ARGUMENTS

STATE-RECOGNITION (iff the recognized state actually obtains; on failure the recognizer's information was wrong).
1. The stated diagnosis names a place the biconditional does not: the recognizer's INFORMATION. Information is held at a strength with its own correctness — the same state recognized as certain and as likely are different performances with the same content, and a lucky guess held as certain is wrong at the strength site while right at the content site.
2. "Actually obtains" is always obtains under some conditions. A recognition carries a situation index; a correct reading of the wrong situation is unsatisfied with the state-type right.
3. "The recognized state" must be a state at all. Recognition-that presupposes a carving of the world into states; if the carving does not fit there is nothing for the world to make true even when every particular datum is correct. This set has no code or language mode, so unlike Jakobson's referential there is nowhere else for the carving to live — it is a gap of this mode.
4. Recognizing that p takes for granted the conditions under which p is statable of this world at all. Those fail on their own, leaving the recognition unsatisfied without any recognized datum being false.

TRANSITION-RECOGNITION (iff the transition is genuinely available OR required AS RECOGNIZED).
1+2. The condition disjoins two satisfiers that fail independently: a move can be open but not owed, and owed but not open. Availability is a fact about whether the world can be moved that way; requiredness rests on whatever makes it owed. The rule can be sound while the move is impossible, and the move easy while no rule requires it.
3. "As recognized" adds a third: the transition must be available IN THE WAY it was recognized. A move genuinely reachable by another route but not the recognized one leaves the recognition unsatisfied. Route is separately failable from bare feasibility.
4. Requiredness is comparative whenever several moves are open — recognizing THIS one as required ranks it above the others. Hold the rule fixed and the move feasible, change the ranking, satisfaction flips.

CONSTITUTION (satisfied by its own successful performance; the status obtains because the recognition is performed AND ACCEPTED).
1. "Successful performance" is procedure-relative: the act must be done in the manner its institution requires, and procedure fails with everything else intact.
2. "And accepted" names a second party's act separately from performance — acceptance is a gap by construction of the condition itself.
3. Constitution makes-so only when done by one entitled to make it so. The identical performance by an unentitled party, correctly proceduralised and warmly accepted, constitutes nothing.
4. The status must exist to be conferred. A properly authorised officer, following correct procedure, accepted by all present, purporting to confer a status for which the governing framework has no provision, has performed completely and constituted nothing. Closest of the twelve to its content site — included because the content site fixes WHICH status is meant, whereas this fixes whether there is such a status to confer.
POSITIVE FINDING, not an oversight: constitution generates NO strength-of-holding gap. Being satisfied by its own performance, there is nothing for a credence to be about.

Σ gaps = 4 + 4 + 4 = 12.

MODE SET C — Habermas's three validity claims

(a) R2 GAP ARGUMENTS

TRUTH (iff the asserted state of affairs obtains).
1. Obtaining is indexed — the state obtains somewhere, at some time, of some situation, and the assertion fixes that index. An assertion true of the situation it describes but put forward about a different one is unsatisfied with its content untouched.
2. Assertion relies on a lifeworld background rather than asserting it; that background can be false while every asserted sentence is true. The carving of the world into states is folded in here — unlike set B, Habermas gives the shared background its own standing, so I do not count a separate scheme site.
3. FLAGGED AS THE WEAKEST SITE IN C: a validity CLAIM is raised, and raising it commits the speaker to redeeming it. Grounds are separately failable from truth in both directions — a true assertion with no grounds cannot be redeemed; well-grounded assertions are sometimes false. Argued from the word "claim", NOT from the biconditional the brief gives, which says only that satisfaction is the state obtaining. A referee holding strictly to the biconditional should drop this and read C as 15.

RIGHTNESS (iff the act is legitimate under those norms).
1. "Under those norms" makes which norms govern separate from whether the act conforms: an act in perfect conformity with the norm the speaker invokes is illegitimate when a different norm actually governs.
2. Legitimacy attaches to an act by a person under a role — the same act by someone without the standing the norms require is illegitimate while the act is unchanged.
3. Norms conflict, so legitimacy under a SET requires a settlement among them. Hold the set fixed, change the ordering, legitimacy flips.
4. The mode is defined over the social world of SHARED norms, so sharedness is textually mandated and is not the same as being in force: two parties can each act under a norm the other does not recognise, each act conforming to the norm its actor holds. (Marginal — the closest call in set C.)
5. Norms govern not only what is done but how. An act can be the right act, by the right person, under the correctly identified and correctly ranked norm, and still breach a norm of manner. NOT the presentation carrier: the carrier is how a token is rendered, whereas this failure is normative and would exist in a face-to-face act with no token to render.

TRUTHFULNESS/SINCERITY (iff the expression matches the inner state).
The same two joints as set A's emotive, for the same textual reason — the condition names the INNER state, not the avowed one. Expression can diverge from what the speaker takes their state to be; what they take it to be can diverge from what it is.
REJECTED: the track record by which a sincerity claim is redeemed over time. Subsequent consistent behaviour is evidence that satisfaction held, not a place where it fails.

Σ gaps = 3 + 5 + 2 = 10.

(b) ENUMERATED SITES (16)

Gaps (10): C4 the situation the assertion is indexed to · C5 the background taken for granted · C6 the grounds that make the claim redeemable [flagged] · C7 which norms are in force · C8 the actor's standing under those norms · C9 the ordering among competing norms · C10 whether the norms are actually held in common · C11 the manner in which the act is carried out · C12 the fidelity of the expression to what is avowed · C13 the accuracy of the speaker's self-reading.
Carrier (3): C14 the encoding used · C15 the presentation given · C16 which instance token this is.

CROSS-SET OBSERVATION (one, and it bears on how you compare these)
The spread 24/18/16 is not noise; it tracks where each mode's satisfier lives. Modes whose satisfier is another agent's act (conative, metalingual, constitution's acceptance) or a normative order (rightness, transition-recognition's requiredness) yield three to five gaps each — the chain from performance to satisfaction has many separately breakable joints. Modes whose satisfier is internal to the speaker (emotive, sincerity) yield exactly two, always the same two, forced by a single word: "actual" in Jakobson, "inner" in Habermas. Modes whose satisfier is bare correspondence (referential, truth, state-recognition) yield two to four, and the variation among them is ENTIRELY about whether the mode set provides somewhere else for the code and the background to live.

Press on that last point. Referential has no carving gap only because Jakobson supplies a metalingual mode to hold it; truth has none only because Habermas's lifeworld background absorbs it; set B has neither, so state-recognition carries both. The same PLACE appears in all three derivations — what differs is which mode it is charged to. Any comparison of these totals that does not control for that is comparing bookkeeping rather than structure, and the deduplicated counts (23, 16, 16) are the numbers I would trust over the raw ones.
