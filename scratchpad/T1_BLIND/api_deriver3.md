### MODE SET A: Recognition Triple (Katsuno-Mendelzon, Millikan, Searle)

#### (a) R2 Gap Arguments (from each mode's satisfaction conditions):

- **State-recognition**: Satisfaction condition: "satisfied iff the recognized state actually obtains". The gap arises because the recognizer's performance (the act of recognizing) is based on information, but the satisfaction depends on the external state. The performance (recognition) can occur even if the state does not obtain (due to wrong information), so satisfaction comes apart from performance at the point of **accuracy of information about the state**.

- **Transition-recognition**: Satisfaction condition: "satisfied iff the transition is genuinely available or required as recognized". The gap arises because the recognizer performs based on their assessment, but the satisfaction depends on the actual availability/requirement in the world. The performance (recognition) can occur even if the transition is not available/required (e.g., misjudgment), so satisfaction comes apart from performance at the point of **correctness of assessment about the transition**.

- **Constitution**: Satisfaction condition: "satisfied by its own successful performance". There is no gap here: satisfaction is achieved by the performance itself (the recognition makes-so). The performance directly satisfies the condition; they do not come apart.

#### (b) Enumerated Sites (named plainly):

1. State-recognition content site (what state-recognition is about: the state of the world)
2. Transition-recognition content site (what transition-recognition is about: the transition)
3. Constitution content site (what constitution is about: the status being made-so)
4. Gap site for state-recognition: accuracy of information about the state
5. Gap site for transition-recognition: correctness of assessment about the transition
6. Carrier site: encoding
7. Carrier site: presentation
8. Carrier site: instance token

- **Rightness**: Satisfaction condition: "satisfied iff the act is legitimate under those norms". The gap arises because the claim is made (performance), but satisfaction depends on the actual norms and their application. The performance (claiming) can occur even if the act is not legitimate (norm violation), so satisfaction comes apart from performance at the point of **conformity to social norms**.

The gap arises because the expression is performed, but satisfaction depends on the speaker's actual inner state. The performance (expressing) can occur even if it does not match the inner state (deception), so satisfaction comes apart from performance at the point of **authenticity of expression**.

### MODE SET C: Jakobson's Six Functions of Language

#### (a) R2 Gap Arguments (from each mode's satisfaction conditions):

- **Referential**: Satisfaction condition: "satisfied when the conveyed information matches the facts". The gap arises because the function is performed (conveying information), but satisfaction depends on the facts. Performance can occur without matching (misinformation), so satisfaction comes apart at **accuracy of reference**.

- **Emotive**: Satisfaction condition: "satisfied when the expression matches the actual attitude". The gap arises because the expression is performed, but satisfaction depends on the actual attitude. Performance can occur without matching (insincerity), so satisfaction comes apart at **sincerity of expression**.

- **Conative**: Satisfaction condition: "satisfied by the addressee's uptake or compliance". The gap arises because the function is performed (e.g., issuing an imperative), but satisfaction depends on the addressee. Performance can occur without uptake/compliance (ignored command), so satisfaction comes apart at **effectiveness on addressee**.

- **Phatic**: Satisfaction condition: "satisfied when the channel in fact holds". The gap arises because the function is performed (e.g., saying "hello"), but satisfaction depends on the channel actually being open. Performance can occur without the channel holding (e.g., no connection), so satisfaction comes apart at **channel availability**.

- **Metalingual**: Satisfaction condition: "satisfied when agreement on the code is reached". The gap arises because the function is performed (e.g., explaining a word), but satisfaction depends on the agreement. Performance can occur without agreement (misunderstanding), so satisfaction comes apart at **mutual understanding of code**.

- **Poetic**: Satisfaction condition: "satisfied by the message's own palpable form doing its work". There is no gap here: satisfaction is achieved by the performance itself (the form working). The performance directly satisfies the condition; they do not come apart.

#### (b) Enumerated Sites (named plainly):

1. Referential content site (what referential is about: the context states)
2. Emotive content site (what emotive is about: the addresser's attitude)
3. Conative content site (what conative is about: the addressee's response)
4. Phatic content site (what phatic is about: the channel)
5. Metalingual content site (what metalingual is about: the code)
6. Poetic content site (what poetic is about: the message form)
7. Gap site for referential: accuracy of reference
8. Gap site for emotive: sincerity of expression
9. Gap site for conative: effectiveness on addressee
10. Gap site for phatic: channel availability
11. Gap site for metalingual: mutual understanding of code
12. Carrier site: encoding
13. Carrier site: presentation
14. Carrier site: instance token

#### (c) Total:
|M| = 6 modes  
Sum gaps = 5 (gaps for all except poetic)  
Carrier sites = 3  
Total = 6 + 5 + 3 = **14**
