# PRE-REGISTRATION — the ecological challenge: exhaustiveness tested from outside the frame

Frozen before any wild item is sampled. The taxonomy's "empirically closed" status rests on
counterexample searches conducted BY its builders — one witness. This study makes the world
the witness: real changes nobody authored for us, classified with NO-FIT first-class, and
the residual read the way content analysis reads its "other" bin — by rate AND by shape.

## 1. Sources — witness diversity for corpora, four unrelated streams

| stream | what it is | why unrelated |
|---|---|---|
| Wikipedia revision diffs | encyclopedic prose edits | crowd, discursive |
| GitHub commit diffs (small, single-hunk) | code and config changes | engineering, mechanical |
| Federal Register amendment redlines | regulatory text changes | legal-institutional |
| OpenStreetMap changesets (tag edits) | structured geographic data edits | schema-shaped, non-prose |

**N = 240 wild items: 60 per stream**, sampled by pinned seed from each stream's own
enumeration (revision ids / commit hashes / docket numbers / changeset ids), restricted to
SINGLE localized changes (one hunk / one clause / one tag), provenance stripped before
annotation. Selection scripts committed with their seeds before any sampling runs.

## 2. Protocol

Identical to the PLANE study's baseline condition (full-retention frame, held design),
same three model families, same prompt — with the two additions the question needs:
NO-FIT is a first-class verdict (already in the prompt), and every NO-FIT or low-agreement
item routes to the FOUR-WAY RESOLUTION TREE (existing kind / composition / different
question / outside the object) at adjudication.

## 3. The staked thresholds — rate AND shape, decided in advance

* **T1 — residual rate.** Adjudicated NO-FIT ≤ **5%** per stream → the taxonomy is
  fit-for-use on that stream. Between 5–15% → domain-limited, the limit named. > 15% in
  any stream → **the taxonomy is short for that domain**, full stop.
* **T2 — the clustering test, the sharp one.** Embed all adjudicated-NO-FIT items
  (three embedding models, majority silhouette). **A residual that CLUSTERS (silhouette
  > 0.25, cluster n ≥ 5) is a missing kind announcing its name** and enters the
  resolution tree as a NEW-PRIMITIVE candidate — this is where 11+1+1 would actually be
  born. A residual that scatters is noise and is reported as noise.
* **T3 — the confusion import.** The wild confusion matrix is compared against the
  authored corpus's: boundary pairs that appear ONLY in the wild are findings about the
  authored corpus's blind spots, reported per the PASS-names-its-rule-set discipline.
* **VOID** if baseline κ on the wild sample's clear-agreement subset < 0.6 — the
  instrument cannot carry the question on wild material, and that is the finding.

## 4. The standing bounty (Beat-the-Taxonomy)

Alongside the ecological arm, a standing adversarial channel per Attenberg–Provost: any
party may submit a change-pair claimed to defeat the twelve; every submission gets the
resolution tree treatment in public; a submission surviving to NEW-PRIMITIVE is credited
by name in the taxonomy's history. The 41st-state challenge on the Babel object is the
bounded version; this is the open-world one.

## 5. Order and budget

After the PLANE pilot verdict (instrument must first prove it can carry AUTHORED material).
Sampling scripts → seed-pinned sample → panel run (240 × 1 condition × 3 models = 720
judgments, ~$0.10 at measured pilot rates, parallel runner) → adjudication → report.
Everything inherits the hard cap.

## 6. What this cannot show

Exhaustiveness is never proved for an open world — chemistry got its proof only when a
GENERATOR (atomic number) turned taxonomy into enumeration. The corresponding open
project here is deriving the twelve from a formal artifact model, at which point
exhaustiveness becomes theorem-given-model like the Babel count. Until then the honest
ceiling is: *closed under our search, closed under the world's typical streams, standing
bounty unclaimed* — three witnesses instead of one.
