# The Common-Person Test — twelve everyday anchors, one per kind, isolation-graded

The steward's requirement, verbatim in force: *clear examples of each label in isolation
that cannot be mistaken for another by a common person. If that is challenging, we have a
problem.* Attempted below, honestly graded. Verdict up front: **12/12 have lay anchors and
lay HANDLES (the phrase ordinary speech already uses); 9 are unmistakable in isolation;
3 carry adjacency risks — and those risks are findings**, because they predict exactly
where annotator confusion will concentrate.

| kind | everyday anchor | the lay handle | isolation |
|---|---|---|---|
| **Priorities** | The triage board changes from "sickest first" to "first come, first served" — nobody newly allowed or refused anything | "they changed who goes first" | clean |
| **Rules** | "Children may swim unaccompanied" → "children must be accompanied" | "that's not allowed anymore" | clean |
| **Manner** | The same eviction notice rewritten from cold legalese to plain, kind language — same deadline, same terms | "they said the same thing differently" | clean |
| **Identity** | The sign now calls the establishment a *clinic* instead of a *spa* — same rooms, same services, same staff | "they're calling it something else now" | **adjacency: Rules** (identity shifts often imply permission shifts; the example must change the claim only) |
| **Confidence** | "It WILL rain tomorrow" → "it will PROBABLY rain tomorrow" | "how sure are they?" | clean |
| **Facts** | "Bridge built 1922" → "1892" | "that's just not true" | clean |
| **Circumstances** | Two receipts identical except the cashier's name and the time of day | "that's just whoever was on shift" | clean |
| **Process** | "Marinate, then grill" → "grill, then marinate" | "you did it in the wrong order" | clean |
| **Model** | The dosage computed from the adult chart instead of the children's chart | "they used the wrong chart" | **adjacency: Rules and Facts** — lay "rules" covers both; the handle splits it: *not allowed* vs *wrong chart* |
| **Structure** | The address written as one unbroken line, so the sorting machine rejects the envelope | "it won't go through the machine" | clean |
| **Premises** | The family budget was built assuming two incomes; one partner quits — every line inherits it | "the whole plan was based on that" | **adjacency: Facts** — the lay discriminator is RIPPLE vs LOCAL: a premise change propagates everywhere, a fact change stays put |
| **Record** | The only copy of the receipt goes through the wash — the purchase can no longer be PROVEN, though you know it happened | "I can't prove it anymore" | clean — and frame-relativity is lay-native: the next question is always *"did the store keep a copy?"* |

## Findings the test produced

1. **The problem the steward feared does not exist** — every kind has an anchor a common
   person already has words for. The taxonomy is carving joints ordinary speech carved
   first. (The strongest case: Record. "Losing the receipt" IS `repairable_does_not_factor`
   in household form, and the common person spontaneously asks the frame question.)
2. **Two NEW boundary pairs surfaced that the prereg did not name**: Identity↔Rules and
   Premises↔Facts. The named set was Confidence/Facts, Model/Facts, Manner/Structure.
   These two join the confusion-matrix watchlist, and the corpus should gain boundary
   items for both (part-B addendum candidate, before annotation).
3. **The lay handles are instrument material**: the annotation prompt's discriminator
   questions and these handles should be tested as ALTERNATIVE instruction sets — if κ
   under handles beats κ under discriminators, the handles are the better instrument, and
   that is measurable inside the existing design.
